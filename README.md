# Smart City Problem Management System

Учебный проект по проектированию информационной системы управления
городскими проблемами (умный город).

**Идея:** жители сообщают о городских проблемах через мобильное приложение
с фотофиксацией и геолокацией, городские службы координируют обращения,
администрация контролирует сроки устранения и видит аналитику.
