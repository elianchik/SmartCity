## 🎯 Видение (Vision)

**Для кого:** жители, городские службы и администрация, которым сложно оперативно сообщать о городских проблемах и контролировать их решение.

**Что делает наша система:**

- 👤 **Жителям** — позволяет сообщать о проблемах через мобильное приложение с фотофиксацией и геолокацией
- 🛠️ **Операторам служб** — координировать обращения и назначать исполнителей
- 📊 **Администрации** — видеть аналитику и контролировать сроки устранения проблем

Система автоматически классифицирует обращения, маршрутизирует их ответственным службам и обеспечивает прозрачный контроль жизненного цикла каждой проблемы.

---

## 👥 Акторы и цели

| Актор | Роль | Цель |
|-------|------|------|
| **Пользователь (мобильный житель)** | Обобщённый актор для всех жителей | Авторизоваться и работать с системой через мобильное приложение |
| **Житель** | Частный случай пользователя | Подать обращение, отследить статус, оценить результат |
| **Оператор городской службы** | Сотрудник диспетчерской | Координировать обращения, назначать исполнителей |
| **Исполнитель работ** | Сотрудник выездной бригады | Получать задания, отчитываться о выполнении |
| **Администратор системы** | Технический администратор | Управлять пользователями, ролями, справочниками |
| **Аналитик городской администрации** | Сотрудник мэрии | Анализировать проблемы, формировать отчёты |

### 🔌 Внешние системы-акторы

| Актор | Стереотип | Что предоставляет |
|-------|-----------|-------------------|
| Картографический сервис | `<<system>>` | Геокодирование, адресная привязка, карта |
| Сервис уведомлений (SMS/push-шлюз) | `<<system>>` | Доставка SMS и push-уведомлений |
| Датчики городской инфраструктуры (IoT) | `<<system>>` | Автоматическая регистрация проблем |

## 🌐 Контекст использования

- 📱 **Мобильное приложение для жителей** (iOS/Android) с геолокацией и фотофиксацией
- 💻 **Веб-кабинет** для оператора, исполнителя, администратора и аналитика
- 📶 Работа в условиях городской среды: возможен слабый интернет — **нужна очередь отправки**
- 🔗 Интеграция с картографическим сервисом, сервисом уведомлений и IoT-датчиками через API
- 🔐 Авторизация — единая для всех ролей (прецедент «Авторизоваться»)

## 📐 Границы проекта (Scope)

### ✅ In Scope (входит в текущую версию)

Функции сгруппированы по акторам из диаграммы прецедентов.

#### Для жителя
- Регистрация и авторизация
- Подача обращения с фото, геометкой, категорией и описанием
- Просмотр карты проблем
- Отслеживание статуса обращения
- Получение уведомлений о статусе
- Оценка результата решения

#### Для оператора городской службы
- Координация обращений
- Назначение исполнителя
- Просмотр входящих обращений и данных датчиков

#### Для исполнителя работ
- Просмотр назначенных работ
- Описание статуса работ
- Фиксация результата работ с фото

#### Для администратора системы
- Управление пользователями и ролями
- Настройка категорий и сроков решения

#### Для аналитика
- Просмотр аналитики по проблемам
- Формирование отчётов

#### Системные функции
- Автоматическая регистрация проблем по данным IoT-датчиков
- Определение местоположения через картографический сервис
- Отправка уведомлений через SMS/push-шлюз

### 🚫 Out of Scope (отложено на будущее)

- Интеграция с системами оплаты и штрафов
- Публичный API для сторонних приложений
- BI-дашборды для руководства
- Голосовой ввод обращений
- Прогнозирование проблем на основе ML
- Интеграция с внешними городскими порталами

## ⚠️ Допущения и ограничения

- Пользователь имеет смартфон с камерой и доступом в интернет
- Геолокация определяется средствами устройства
- Службы обязаны реагировать в установленные регламентом сроки
- Система **не гарантирует** физическое устранение проблемы — только фиксацию, маршрутизацию и контроль
- Данные обращения и его статус доступны без входа только при указании **уникального номера обращения и отдельного кода доступа**
- Незарегистрированный пользователь может создавать обращения и проверять их статус, но **не может** изменять служебные данные или назначать исполнителей
